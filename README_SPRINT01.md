# EXO Murim — Haneul Sprint 01: Terreno Manhwa

**Projeto integral:** baseado EXCLUSIVAMENTE em Haneul V0.4 + Character Core Motion V3. Copie a pasta completa para nova pasta (nunca faca merge sobre V0.4).

Motor Godot 4.7.2 Standard, modo Compatibility. Abra `project.godot`, importe, aperte F5.

Mudancas neste sprint: 16 texturas originais de solo, pintura continua na malha, transicoes suaves entre estrada, grama, prata de pedra, margens do Rio Hwa. O renderer exibe a NOVA superficie e conserva a malha antiga invisivel como colisao. O mapa fisico, as edificacoes e as animacoes NAO foram modificadas.

Para avaliar qualidade visual, confira `previews/01_PALETA_16_TEXTURAS_MURIM.png` e `previews/02_TEXTURA_TERRENO_APLICADA_MAPA.png`.

**Teste real Godot e capturas:** consulte `qa/sprint01/` apos validar. Android nao foi executado. Grama 3D/props sao do modelo anterior, nao refeito neste sprint.
