# Assets de terreno — EXO-Murim 09.4.6

As oito texturas PNG de `assets/terrain/`, seu script gerador e o kit procedural de grama/rochas foram criados especificamente para o projeto nesta atualização, sem copiar texturas de Minecraft, Toram ou bibliotecas externas. Podem ser editados, redistribuídos com o jogo e usados comercialmente pelo proprietário do EXO-Murim.

Dependências de ferramentas: Python + Pillow + NumPy apenas para *regenerar* as texturas; não são necessárias para executar o jogo, pois os PNGs estão incluídos.

Os demais assets e suas licenças pré-existentes são preservados; esta nota não modifica licenças de modelos de terceiros já integrados.
