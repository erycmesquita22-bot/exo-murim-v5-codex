# Fontes e reprodução

Os arquivos `build_harmonizacao.py`, `render_glb.py`, `render_motion.py` e `finalizar.py` são scripts Python de autoria desta harmonização. Para reconstruir a entrega a partir dos arquivos originais, posicionar `EXO-Murim-Creature-Forge-01.zip`, `EXO-Murim-Creature-Art-02-CANDIDATO.zip` em `/mnt/data` e `EXO-Murim-Bestiario-Inimigos-02.zip` em `/mnt/data/bestiario_referencias/`, preservando estrutura. Scripts são de checkpoint e contêm caminhos absolutos de ambiente; para portar para outro sistema, parametrizar `SRC`, `ROOT` e `OUT` antes de executar. `numpy`, `Pillow`, `numba`, `scipy` são usados para QA/prévias; não são dependências do runtime do jogo. Nunca executar o `finalizar.py` num projeto Godot de produção. Os outputs de produção são as cenas e GLBs já incluídos.
