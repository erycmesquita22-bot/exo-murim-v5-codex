# Procedência

As geometrias deste pacote foram criadas por código para o projeto EXO-Murim; não foram incluídos modelos 3D baixados de sites de assets. O código de construção está em tools/build_assets.py.

As imagens dos quatro atlas foram geradas com ImageGen nesta conversa e selecionadas pelo proprietário como base visual. Os recortes preservam seus pixels; os originais e os hashes estão incluídos. As pranchas conceituais têm a mesma origem e estão identificadas como conceito.

O pacote foi preparado para uso e adaptação no EXO-Murim, incluindo sua finalidade comercial. Este registro descreve a procedência; não alega exclusividade artística, registro autoral ou auditoria jurídica de titularidade.

Godot, NumPy, Pillow e trimesh foram ferramentas de produção/validação. Não acompanham binários de engine ou cópias de bibliotecas Python neste ZIP; as versões de reconstrução estão no requirements.txt.
