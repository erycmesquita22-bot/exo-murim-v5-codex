# EXO Haneul — Cultivation Path 04

Projeto Godot independente da vila HWA-02 com o módulo de cultivo do jogador. Abra `project.godot` no Godot Standard com renderer Compatibility. Cena inicial: `modules/village_npcs/VillageNPCs_V11.tscn`.

O código e os assets aqui pertencem à linha Haneul/Village Life; este repositório não é a integração do EXO V5. Para instruções do cultivo, consulte [o módulo](modules/cultivation_path/README.md). Para testes executados e limitações, consulte [o relatório](qa/cultivation_path_04/REPORT.md).

A arte V4 e os assets de referência foram mantidos sem alteração visual. A homologação comercial das fontes e o teste em Godot 4.7.2 continuam pendentes.
